# Permutation Moduli Spaces and the Minimal Superpermutation Problem

This repository contains the source code, data, and figures for the paper:
**"On the Intersection Theory of Permutation Moduli Spaces and the Solution to the Minimal Superpermutation Problem"**
by Sang-Bin Park.

## Contents

*   `verify_C_geom.ipynb`: A Jupyter Notebook to reproduce all calculations and figures in the paper.
*   `figure_1_research_flow_EN.svg`: Figure 1 of the paper.
*   `figure_2_recursive_construction_EN.svg`: Figure 2 of the paper.
*   `figure_3_proof_roadmap_EN.svg`: Figure 3 of the paper.
*   `figure_4_visual_verification_EN.png`: Figure 4 of the paper.

## How to Use

To verify the results, please open `verify_C_geom.ipynb` in a Jupyter environment (like Jupyter Lab or VS Code) and run all cells.
